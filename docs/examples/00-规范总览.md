# 任务规范(所有场景通用的核心格式)

三种视图都读这一套语法,任何 `.md` 文件、任何位置都生效:

## 任务行

```markdown
- [ ] 任务内容 @due(2026-10-16) #工作
```

| 组成 | 必填 | 作用 | 影响的视图 |
|---|---|---|---|
| `- [ ]` / `- [x]` | 是 | 未完成 / 已完成 | 全部(勾选即写回) |
| `任务内容` | 是 | 显示文本 | 全部 |
| `@due(YYYY-MM-DD)` | 否 | 截止日期 | 日历落格;过期未完成显示红色 |
| `#标签` | 否 | 分类(第一个标签决定看板列) | 看板列;每个标签一个颜色 |

## 规则

1. **一个标签 = 看板的一列**。当前默认列:`#工作` `#生活`。用其他标签会自动新建列(如 `#学习` `#差旅`)。多标签 `- [ ] x #工作 #紧急` 取第一个做列。
2. **日期必须 `YYYY-MM-DD`** 完整格式,放进 `@due(...)` 括号里。
3. 任务行可以是任何列表层级,嵌套子任务照常解析:
   ```markdown
   - [ ] 期末项目 #学习
     - [ ] 选题 @due(2026-10-20) #学习
     - [x] 开题报告 @due(2026-10-15) #学习
   ```
4. 所有视图的勾选/拖拽都是**直接改写这一行 markdown**(可 Cmd+Z 撤销,git diff 只有一行)。

## 建议:一场景一文件

文件名即看板卡片的来源标注。推荐结构:

```
~/notes/
  任务.md          # 主任务收件箱(周计划、杂项)
  学习/作业.md     # 作业追踪
  学习/复习.md     # 复习计划
  文献/文献库.md   # 文献整理(见 03-文献.md 案例)
  生活/习惯.md     # 习惯追踪
  生活/财务.md     # 记账
  生活/旅行-京都.md # 旅行计划
  work/项目-x.md   # 团队项目
```

视图扫的是**当前 lite-xl 打开的项目目录**下的所有 `.md`,所以把这些文件放在你打开的工作区里即可。
