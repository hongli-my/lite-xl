# 案例一:作业追踪(学生场景)

文件:`学习/作业.md`。看板按 `#作业` `#复习` `#项目` 分列,日历看本周交什么。

```markdown
# 作业追踪 · 2026 秋

## 本周

- [ ] 线性代数 习题四 P87 1-8 @due(2026-10-16) #作业
- [ ] 概率论 习题三 全部 @due(2026-10-14) #作业
- [ ] 英语 精读 Unit 5 预习 @due(2026-10-15) #作业
- [x] 编译原理 lab2 词法分析 @due(2026-10-10) #作业

## 复习计划(期中)

- [ ] 复习:特征值与对角化 @due(2026-10-20) #复习
  - [ ] 重看 lecture 12-14 笔记 #复习
  - [ ] 第三章思维导图重画一遍 #复习
- [ ] 复习:CLT 与假设检验 @due(2026-10-22) #复习
- [x] 复习:图算法总结 @due(2026-10-12) #复习

## 期末项目

- [ ] 期末项目:确定选题 @due(2026-10-18) #项目
- [ ] 期末项目:文献调研 10 篇 @due(2026-10-25) #项目
```

要点:

- 嵌套子任务(缩进两格)是父任务的分解,看板里每张卡独立,来源标注 `学习/作业.md:9` 这样的行号。
- 逾期红线:今天是 10-13,`10-12` 未完成的自动红色。
- 交完一项就在看板点 ☑,或编辑器里改 `[x]`——同一份数据。
