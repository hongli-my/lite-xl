文件:`学习/复习导图-线代.md`:

```markdown
# 线性代数 · 期末复习

- 特征值与特征向量
  - 定义 Av = λv
  - 求法 det(A-λI)=0
  - 几何意义:缩放不变的方向
- 相似对角化
  - 条件:n 个线性无关特征向量
  - 步骤
    - 求特征值
    - 求特征向量
    - 组装 P 与 D,A = PDP⁻¹
  - 失败情形:Jordan 标准形
- 应用
  - 矩阵幂 Aⁿ
  - 微分方程组 ẋ = Ax
  - 谱分解与主成分
```
