# 案例六:周计划(总入口)

文件:`任务.md`——所有场景的收件箱 + 每周节拍器。

```markdown
# 我的任务

## 本周(10-13 ~ 10-19)

- [ ] 周一:定本周三个重点 #周计划
- [ ] 线代习题四 @due(2026-10-16) #作业
- [ ] 和导师约 M2 中期评审 @due(2026-10-15) #工作
- [ ] 精读 wang2025 第 3 章 @due(2026-10-18) #文献
- [ ] 订京都民宿 @due(2026-10-20) #差旅
- [ ] 周日:本周复盘(勾掉未完成项转移下周) @due(2026-10-19) #周计划

## 本周三个重点

- [ ] 期末项目选题定稿 #项目
- [ ] M2 Canvas MVP 跑通拖拽 #工作
- [ ] 线代复习过半 #复习

## 收件箱(未排期)

- [ ] 试用 AFFiNE 对比记录 #想法
- [ ] 给 lite-xl 提个 feature request #想法
```

## 使用节奏

| 时间 | 动作 |
|---|---|
| 周日晚 | 清收件箱 → 排下周任务(补 `@due` 和 `#标签`) |
| 每天 | 看板/日历过一遍,完成的当场 ☑ |
| 任何时候 | 新想法直接丢收件箱,不分类 |
| 下周日晚 | 未完成的拖去下周,改日期 |

## 标签体系建议(看板列即分类)

| 标签 | 用途 | 对应场景文件 |
|---|---|---|
| `#工作` | 职业任务 | `work/项目-x.md` |
| `#作业` | 学生课业 | `学习/作业.md` |
| `#复习` | 考试复习 | `学习/复习.md` |
| `#文献` | 阅读进度 | `文献/文献库.md` |
| `#项目` | 个人项目 | 各项目文件 |
| `#生活` `#差旅` | 生活事务 | `生活/` 下各文件 |
| `#想法` | 收件箱未分类 | `任务.md` |

要点:

- `任务.md` 只放**跨场景**的东西:本周节拍、收件箱、周重点。具体场景的细节任务放各自的场景文件(作业.md / 文献库.md / 项目-x.md),视图自动全聚合。
- 列会自动按出现顺序追加,建议把高频标签写进配置固定顺序:
  ```lua
  config.plugins.todo_agenda = {
    kanban_columns = { "工作", "作业", "复习", "文献", "项目", "生活", "差旅", "想法" },
  }
  ```
- 看板卡片上标注了来源(`任务.md:5`),双击卡片跳到源文件(阶段 2 起);目前点列表行文字即可跳转。
