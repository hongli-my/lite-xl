## 团队 wiki 用法

- 决策记录(ADR)、会议纪要都写成上述结构,任务行混在正文里自动进看板
- `[[ADR-001]]` 双链引用;同目录 `adr-001.md` 存正文
- git 仓库即 wiki:提交历史 = 变更审计,不需要额外权限系统

## 评审演示

markdown 里用 `---` 分隔的内容段落,阶段 4 演示模式按分隔分页放映:

```markdown
---

## M2 进度

- 卡片拖拽 ✓
- 箭头连接 ✓
- Frame 放映 — 进行中

---
```

要点:

- 里程碑即看板列:`#M1` `#M2`…一列一个里程碑,泳道式路线图
- 评审待办直接 `- [ ] ... @due() #M2`,散会即任务,不换工具
